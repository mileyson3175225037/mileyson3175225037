1. Introducción

Bienvenido a TuSOAT. Estos Términos y Condiciones regulan el acceso y uso de nuestro sitio web y de los servicios ofrecidos a través de la plataforma.

Al utilizar nuestro sitio web, el usuario declara que ha leído y comprendido estos Términos y Condiciones y acepta cumplirlos.

```
```

2. Identificación de TuSOAT

TuSOAT es una plataforma digital destinada a facilitar el acceso a servicios relacionados con seguros y documentación para vehículos.

```
```

3. Objeto del sitio web

TuSOAT tiene como finalidad proporcionar a los usuarios información y facilitar el acceso a servicios relacionados con seguros obligatorios y otros servicios para vehículos, de acuerdo con las opciones disponibles en la plataforma.

```
```

4. Registro de usuarios

Para utilizar determinadas funciones de TuSOAT, el usuario podrá necesitar crear una cuenta proporcionando información solicitada durante el proceso de registro.

El usuario se compromete a proporcionar información verdadera, completa y actualizada.

El usuario es responsable de mantener la confidencialidad de sus credenciales de acceso y de informar cualquier uso no autorizado de su cuenta.

```
```

5. Uso adecuado de la plataforma

El usuario se compromete a utilizar TuSOAT de manera legal, responsable y de acuerdo con estos Términos y Condiciones.

Está prohibido utilizar la plataforma para realizar actividades fraudulentas, introducir información falsa, intentar acceder a cuentas de terceros o afectar el funcionamiento de la plataforma.

```
```

6. Información del vehículo

El usuario deberá verificar que los datos proporcionados durante cualquier proceso relacionado con su vehículo sean correctos antes de continuar con una operación.

TuSOAT no será responsable por inconvenientes derivados directamente de información incorrecta proporcionada por el usuario, sin perjuicio de los derechos que le correspondan conforme a la legislación aplicable.

```
```

7. Proceso de compra

Cuando el servicio de compra se encuentre disponible, el usuario deberá proporcionar la información solicitada, revisar los datos de la operación y confirmar su intención de realizar la compra.

Antes de finalizar una transacción, el usuario deberá verificar la información presentada, incluyendo los datos del vehículo, el precio y las condiciones de la operación.

```
```

8. Precios y medios de pago

Los precios y las condiciones económicas aplicables serán informados al usuario antes de finalizar la operación, de acuerdo con el servicio seleccionado.

```
```

9. Emisión del SOAT

La emisión del SOAT estará sujeta a la validación de la información proporcionada por el usuario y a las condiciones aplicables al proceso correspondiente.

```
```

10. Entrega de la póliza

La forma y condiciones de entrega de la documentación correspondiente serán informadas al usuario durante el proceso de compra.

```
```

11. Cancelaciones, devoluciones y derecho de retracto

Las condiciones aplicables a cancelaciones, devoluciones y ejercicio de los derechos del consumidor serán informadas de acuerdo con la naturaleza del servicio y la legislación colombiana aplicable.

```
```

12. Protección de datos personales

El tratamiento de los datos personales proporcionados por los usuarios se realizará de acuerdo con la legislación colombiana aplicable y con la Política de Tratamiento de Datos Personales de TuSOAT.

Para conocer cómo recopilamos, utilizamos, almacenamos y protegemos los datos personales, el usuario podrá consultar nuestra Política de Tratamiento de Datos Personales.

```
```

13. Propiedad intelectual

Los elementos que forman parte de TuSOAT, incluyendo diseños, logotipos, textos, gráficos, imágenes, código, elementos visuales y demás contenidos propios, podrán estar protegidos por las normas aplicables de propiedad intelectual.

No está permitido reproducir, modificar, distribuir o utilizar dichos elementos sin la autorización correspondiente, salvo cuando la legislación permita expresamente dicho uso.

```
```

14. Seguridad de la plataforma

TuSOAT implementará medidas razonables de seguridad destinadas a proteger la información y el funcionamiento de la plataforma.

El usuario también deberá adoptar medidas adecuadas para proteger sus credenciales y dispositivos utilizados para acceder a su cuenta.

```
```

15. Disponibilidad del servicio

TuSOAT procurará mantener disponible la plataforma y sus servicios, pero pueden presentarse interrupciones derivadas de mantenimiento, actualizaciones, fallas técnicas o circunstancias fuera de su control.

```
```

16. Atención al usuario y PQRS

Los usuarios podrán comunicarse con TuSOAT para presentar preguntas, peticiones, quejas, reclamos o solicitudes a través de los canales de atención disponibles.

```
```

17. Modificación de los Términos y Condiciones

TuSOAT podrá actualizar estos Términos y Condiciones cuando resulte necesario debido a cambios en los servicios, en la plataforma o en la normativa aplicable.

Las modificaciones serán publicadas en esta página para que los usuarios puedan consultarlas.

```
```

18. Legislación aplicable

Estos Términos y Condiciones se regirán e interpretarán de conformidad con las leyes aplicables de la República de Colombia.
